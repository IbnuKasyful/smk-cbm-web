# Images

Drop real SMK CBM photos here and reference them from components, e.g.
`/images/gedung-cbm.jpg`. Until then, the site uses CSS gradient placeholders
(the `.photo` class in `app/globals.css`).

Suggested assets:
- `gedung-cbm.jpg` — main building (Hero background)
- `lab-farmasi.jpg`, `asrama.jpg`, `dapur.jpg` — facilities
- event / news thumbnails (or set Featured Images in WordPress instead)
